🚀 HOW TO USE:
═════════════

OPTION 1: Manual Testing (Via UI)
  1. Open index.html in browser
  2. Enter values manually
  3. Click "Add Value" button
  4. Watch patterns detect

OPTION 2: Bulk Import (Via UI)
  1. Copy: 1.50, 2.30, 0.95, 1.80, 2.45
  2. Paste in text area
  3. Click "Add Bulk Values"
  4. All patterns detect automatically

OPTION 3: Live Game Capture
  1. Click "🎮 Open Aviator Game"
  2. Click "🔴 Start Auto Capture"
  3. Game values auto-extract
  4. Patterns detect in real-time

OPTION 4: Console Commands
  window.app.engine.addValue(1.50);
  window.app.engine.getPatterns();
  window.app.engine.analyzeSequence();
  window.app.engine.exportReport();
